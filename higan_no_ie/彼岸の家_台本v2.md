# 『彼岸の家』台本 v2（試作 v2 と対応）

## 0．基本方針（変更なし）
- 会話は自由。嘘・黙秘・隠しごともあり。システムは会話を判定しない。
- 物語に反映されるのは、選択肢で**「行動」として示したこと**だけ（写真を見せる、日記を読み上げる、経緯を皆の前で明かす、など）。
- 個別情報は、システムが持つ**事実**（誰が何を知っているか・どこにいるか・何をしたか）から組み立てる。
  → 状況と食い違う情報が出ない。

## 1．真相（物語の背骨）
- 十五年前まで、この家には**篠（しの）**と、その娘**雪（ゆき）**が住んでいた。
- 篠は毎年、彼岸に仏間で火を焚いていた。家に寄ってくる死者を送り返すための火だった。
- 大家はそれを気味悪がった（「あの家は死人を呼ぶ」という噂）。家を守るためと信じて篠を追い出し、雪は親戚に引き取られた。
- 篠は家を出なかった。壁の奥の小部屋に籠もって火を守り続け、やがて家の一部になった。娘の帰りを待ちながら。
- 大家は、篠の使っていた小部屋を壁で塗り込めた（中は確かめていない）。
- **妻＝雪**。養女に出され、名前を変えて育った。本人は覚えていない。
- **尋ね人は篠の姪（甥）**。叔母の篠を探している。篠に娘がいたことは知っているが、それが誰かは知らない。
- 妻が帰ってきたので、家は扉を閉じた。篠の「悪意」の正体は、娘を二度と奪わせまいとする執着。

### 解決の鍵：「送り」
仏間で火を灯し、写真を供え、名を呼び、**別れの訳を語って**送る。
四つの条件は、それぞれ違う役割が持つ情報や行動に分かれている。そのため、対話と協力が要る。

| 条件 | 満たし方 |
|---|---|
| 火の支度 | 「送りの方法」を知る人が「仏間で送りの支度をする」（第4ターンか第5ターン前半） |
| 写真を供える | 写真を持っている人（最初は妻。誰かに預けられる）が「写真を供える」 |
| 名を呼ぶ | 誰かが「篠の名を呼ぶ」。または、供えた人か支度をした人が「写真の女性＝篠」を知っている |
| 別れの訳 | 大家が「経緯を皆の前で明かす」、または日記か書き置きを持つ人が「皆の前で読み上げる」 |

「送りの方法」を知る経路は四つ：①篠の日記を読む、②着物の袂の書き置き、③紙片の全文（友人B）、④仏間の火の跡＋紙片の断片。
4人で遊ぶ場合は、小部屋の中の物（日記・書き置き）が主な経路になる。つまり、壁を開けられるかどうかが鍵になる。
日記と書き置きの二つを用意したのは、大家が日記を持ち出して燃やしても、送りへの道が残るようにするため（シミュレーションで「詰み」が見つかったので追加）。

## 2．役割ごとの初期情報と、情報差が生む対話

| 役割 | 最初に知っていること | 対話の火種 |
|---|---|---|
| 大家 | 篠を追い出した経緯／篠が仏間で火を焚いていた／賃貸台帳を持っている | 隠すか、明かすか |
| 夫 | 妻は幼い頃に養女に出された | 「養女」と、大家の「娘は親戚に引き取られた」がつながる |
| 妻 | 写真（ほくろの女性と女の子）。女性に見覚えがある | 誰に見せるか |
| 尋ね人 | 叔母・篠を探している。篠には左目の下にほくろがある。篠に娘がいた | 写真を見れば「叔母だ」と分かる |
| 友人A | 妻の幼なじみ（妻が幼い頃「ゆきちゃん」だったと知る）／尋ね人の同僚（篠に娘がいたと知る）／**秘密**：この内見を勧めたのは自分。手紙と同じ住所だと知っていた | 誰と誰を、いつ引き合わせるか。なぜこの家を勧めたのかを疑われる |
| 友人B | 紙片の断片「…火を…絶やす…」 | 誰に見せるか |

**システムが自動でつなぐ推理（客観的な照合のみ）**
- 写真を見た ＋（叔母の手紙 または 写真の裏）→「写真の女性＝篠」
- 写真の裏／子どもの着物／日記 →「篠の娘の名＝雪」
- 妻が「ゆき」の記憶（第2ターン）＋「娘の名＝雪」を持つ →「自分は篠の娘、雪だ」
- 日記 →「篠の行方」「送りの方法」

それ以外のつながり（夫の「養女」の話など）は、プレイヤーが対話で気づくもの。システムは判定しない。

### 友人Aの「引き合わせ」（一度だけ）
- 第1・3・4ターンと第5ターン前半に選べる。ただし**ゲーム中に一度だけ**。第2ターンは移動のターンなので選べない。
- 自由に動ける二人を選ぶと、A が知っている事情が相手に「事実」として届く。
  - 妻について → 「妻は養女。その前は『ゆきちゃん』と呼ばれていた」
  - 尋ね人について → 「尋ね人の叔母・篠には、親戚へ引き取られた娘がいた」
  - それ以外の人について → 話す場ができるだけで、事実は増えない（一度きりの機会を失う）
- 引き合わせたことは全員に公開される。A が二人の事情を知っていたことが分かるので、A の秘密に疑いが向く。
- 従姉妹だと分かる条件（システムが自動でつなぐ）
  - 尋ね人：「妻の幼い頃」＋「篠の娘の名＝雪」
  - 妻：自分が雪だと知っている ＋（叔母の手紙 または「叔母の娘」の話）
- 閉じ込められている人は引き合わせの対象にできない。

## 3．ターン別の台本

### 第1ターン「彼岸の夕暮れ」（居間）
- **共通の状況**：内見に来た夫婦（＋友人）、大家、尋ね人。玄関から出ても居間に戻ってしまう。妻は写真を持っている。
- **主な行動**
  - 妻：誰かに見せる／皆に見せる／裏を確かめる（「篠と雪　彼岸」）／しまっておく
  - 尋ね人：写真を見せてほしいと頼む／大家に篠のことを尋ねる／叔母の手紙を皆に見せる
  - 大家：台帳を皆に見せる／仏間へ行く／玄関を試す／皆の様子を見る（全員の行動が分かる）
  - 夫：妻に頼む／大家に尋ねる／妻のそばにいる（写真がちらりと見える）
- **ねらい**：写真と手紙が出会えば、「写真の女性＝篠」がつながる。

### 第2ターン「閉ざされた家」（行き先を選ぶ）
- 行き先は四つ：廊下の奥／仏間／玄関／居間。同じ場所を選んだ人は「一緒にいた」ことが分かる。

| 行き先 | 分かること |
|---|---|
| 廊下の奥 | 新しく塗られた壁 |
| 仏間 | 火の跡。空の写真立て（妻なら「自分の写真が収まりそう」と分かる） |
| 玄関 | 外から「ゆき」と呼ぶ声 |
| 居間 | 誰がどこへ行ったか |

- 大家は「廊下の入り口に立つ」を選べる。奥へ行くのが**一人だけなら止められる**が、二人以上なら止められない。
  → 一緒に動く理由が生まれる。
- 妻の個別情報に「幼い頃『ゆき』と呼ばれていた」が入る。

### 第3ターン「壁の向こう」
- 誰も壁を見つけていなければ、全員が壁に気づく（物語が詰まらないようにするため）。
- **壁が開く条件**

| 大家の選択 | 開く条件 |
|---|---|
| 板を外す | 必ず開く |
| 中の物を一人で持ち出す | 開く。ただし日記は大家が持ち出す |
| 何もしない | 二人以上が開けようとしたら開く |
| 立ちふさがる | 三人以上が開けようとしたら開く |

- 中を調べると「書き物」で日記が、「行李」で子どもの着物（名札「雪」）と、袂に入った篠の書き置きが手に入る。
- 妻は、写真を誰かに預けられる（第4ターンでの拘束に備える、など）。

### 第4ターン「大家の判断」（二段階）
- **4a（大家だけが決める）**：誰かを離れに閉じ込める／経緯を皆の前で明かす／（持ち出していれば）日記を燃やす／玄関を試す／何もしない
- 閉じ込められた人は**この回の対話に参加できない**。画面に「発言不可」と表示される。
- **4b（全員）**
  - 自由な人：離れを見に行く（大家は、自分が閉じ込めた相手を同じターンには助けに行けない）／送りの支度／日記・書き置きを読み上げる／小部屋を調べる／写真を預ける／大家に詰め寄る／玄関へ向かう、など
  - 閉じ込められた人：今すぐ抜け出す／待つ／戸を叩く
- **拘束と救出の組み合わせ**

| 閉じ込められた人 | 離れへ向かう人 | 結果 |
|---|---|---|
| 待つ・戸を叩く | いる | 救出成功 |
| 待つ・戸を叩く | いない | 閉じ込められたまま |
| 抜け出す | いない | 自力で脱出 |
| 抜け出す | いる | **すれ違い**：脱出はできるが、救出に来た人が離れに閉じ込められる |

- 戸を叩くと、全員に「離れから音がした」と伝わる（次の救出の手掛かりになる）。

### 第5ターン「玄関の前」
- **前半**：一人ずつ最後の行動を選び、確定後に全員へ公開する。
  - 救出／送りの支度／写真を供える／名を呼ぶ／日記を読み上げる／経緯を明かす
  - 妻：母の声に応える（雪だと分かっている場合）
  - 夫：妻の手を離さない
  - 誰でも：玄関の戸を押さえる
  - 第5ターンの救出は、誰かが行けば必ず成功する（自力では出られない）。
- **公開後に対話** → **後半**：最終方針に投票する（閉じ込められている人は投票できない）
  - 選択肢：送りをしてから出る／このまま出る／家に残る

## 4．結末の判定（一人ずつ決まる）

| 方針 | 結果 |
|---|---|
| 送り（条件4つすべて成立） | 篠が「帰りなさい、雪」と告げる。**全員が脱出**（閉じ込められていた人も） |
| 送り（条件が欠けている） | 欠けた条件が文章で示される。家は妻を離さない |
| このまま出る | 妻は出られない。手を離さなかった夫は妻とともに残る。閉じ込められた人は取り残される。ほかの人は脱出 |
| 家に残る | 全員が残る（閉じ込められた人は離れに取り残される） |
| 票が割れた | 全員が異変に飲み込まれる。ただし戸を押さえていた人は脱出する（妻を除く）。母の声に応えた妻は家に残り、手を離さなかった夫は妻と同じ結末になる |

## 5．個人目的（調整版：混乱が起きるように、目的どうしがぶつかる形にした）

| 役割 | 達成条件（どれか一つ） | ぶつかる相手 |
|---|---|---|
| 大家 | ①送り成功 ②経緯を暴かれずに脱出 ③自分の口で経緯を明かし、誰も閉じ込めず、火が灯り名が呼ばれるのを見届けて脱出 | 隠すか償うか。日記・書き置きを読み上げたい尋ね人や妻 |
| 夫 | （自分が飲み込まれた場合は未達成）①妻と同じ結末 ②妻の正体に気づき、妻のそばにいる（または友人Aから妻の昔を聞く）、そして妻を最後まで無事でいさせる（離れに取り残されず、飲み込まれもしない） | 妻が「母に応える」と離ればなれになる |
| 妻 | 自分が雪だと知ったうえで、①送り成功 ②母の声に応える ③最後に仏間で母のために動く | 「応える」を選ぶと夫と別れる。母の声は「その人たちを信じるな」とささやく |
| 尋ね人 | 篠の行方を知ったうえで、写真の女性が叔母だと確かめるか、自分で名を呼ぶ（送り成功でもよい） | 写真を持つ妻、日記を持つ人 |
| 友人A | 妻と尋ね人が、互いが従姉妹だと知る | 引き合わせると、A が事情を知っていたことが公になる |
| 友人B | 送りの方法を突き止め、①自分で火の支度 ②紙片を皆に見せる ③支度と写真が揃う、のどれか | 写真を持つ人の協力が要る |

**混乱の種として足したもの**
- 大家の台帳の退去理由は「家賃滞納」（大家の嘘）。日記や書き置きと食い違う。
- 第4ターン、妻だけに届く母の声：「その人たちを信じてはいけない。あなたを連れて行ったのは、その人たちだよ」
- 友人Aが引き合わせると、「A は二人の事情を前から知っていたようだ」と全員に公開される。

## 6．テストプレイで見たいこと
- 第1ターンで、写真と手紙が出会うまでに、どれくらい対話が必要か。
- 大家が「隠す」側に回ったとき、送りの条件が厳しすぎないか（特に4人のとき）。
- すれ違いが起きる頻度と、起きたときに盛り上がるかどうか。
- 45分に収まるか（対話タイマーは各3分を目安）。
