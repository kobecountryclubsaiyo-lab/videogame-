# videogame-

## 彼岸の家（`higan_no_ie/`）

古い日本家屋を舞台にした、対話型のミステリー・ホラーゲームの試作です。

- 人数：4〜6人（大家・夫・妻・尋ね人＋友人A・B）
- 時間：約45分（全5ターン）
- 進行：共通の状況 → 個別情報 → 対話 → 個別選択 → 結果描写
- 会話は自由です。システムは会話を判定せず、選択肢で示した「行動」だけを物語に反映します。

### 遊び方
`higan_no_ie/index.html` をブラウザで開きます。1台の端末を順番に受け渡して遊びます（端末を渡すたびに目隠し画面が出ます）。
